# 🏫 نظام إدارة إعدادية النهرين المهنية (Al-Nahrain Vocational School System)

مرحباً بك في المستودع الرسمي لنظام إدارة إعدادية النهرين المهنية. هذا المشروع عبارة عن منصة تعليمية ذكية متكاملة تعتمد على أحدث تقنيات الويب، مصممة لتسهيل إدارة العملية التعليمية وربط الطلاب والأساتذة والإدارة في بيئة رقمية موحدة.

## ✨ مميزات النظام (Features)

يحتوي النظام على مجموعة واسعة من الأدوات المتقدمة:

*   **☁️ قاعدة بيانات سحابية (Firebase Integration):**
    *   ربط فوري للبيانات (Realtime Database).
    *   إمكانية الوصول للنظام من أي جهاز (هاتف، حاسوب، تابلت).
    *   نظام مزامنة تلقائي (Sync) لحفظ البيانات من الضياع.

*   **🤖 مساعد ذكي (Nahr-AI):**
    *   نظام ذكاء اصطناعي تفاعلي يجيب على استفسارات الطلاب صوتياً وكتابياً.
    *   دعم للأسئلة الشائعة (الأقساط، التخصصات، الموقع، أوقات الدوام).
    *   توليد صوتي عربي متطور (Text-to-Speech).

*   **📱 نظام إدارة شامل (Admin Dashboard):**
    *   **للإدارة:** لوحة تحكم لإضافة الأساتذة والطلاب، ومراقبة الحضور.
    *   **للمدرسين:** واجهة لرصد الدرجات وتسجيل الملاحظات لكل طالب.
    *   **للطلاب:** بوابة خاصة لمتابعة الجدول الدراسي والدرجات والغيابات.

*   **🔒 نظام أمان ومحاكاة (Security & Tools):**
    *   نظام تسجيل دخول آمن (Authentication).
    *   محاكاة لنظام الحضور عبر بطاقات (NFC Simulation).
    *   استمارة تقديم وقبول إلكترونية متطورة للطلاب الجدد.

*   **🎨 واجهة مستخدم (UI/UX):**
    *   تصميم عصري (Glassmorphism) مع مؤثرات بصرية.
    *   متجاوب بالكامل مع جميع الشاشات.
    *   وضع ليلي (Dark Mode) افتراضي بتصميم "سايبر بانك" تعليمي.

## 🛠️ التقنيات المستخدمة (Tech Stack)

*   **HTML5 / CSS3:** للهيكل والتصميم.
*   **Vanilla JavaScript (ES6+):** للمنطق والبرمجة.
*   **Firebase Realtime Database:** لتخزين البيانات سحابياً.
*   **Web Speech API:** لتقنيات التحدث الصوتي.
*   **FontAwesome:** للأيقونات.

## 🚀 كيفية الاستخدام (How to Run)

1.  **للتشغيل المحلي:** فقط قم بفتح ملف `index.html` في أي متصفح حديث (Chrome/Edge).
2.  **للنشر:** ارفع الملفات إلى GitHub Pages أو Netlify وستعمل فوراً.
